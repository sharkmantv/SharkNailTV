# IBO SKY RETRO — OwnTV-based complete player

This is the real open-source OwnTV Android TV application with a SKY RETRO-style 8-card Home surface, **not** an IBO Pro APK or a fork of proprietary IBO code.

Source base: https://github.com/ahXN00/OwnTV at pinned commit 88e5440625fdf671dde28c785f803bd1b1c16f23 (22 Nov 2026).
Shared core/Media3 and mpv engine are provided by https://github.com/ahXN00/OwnTV_Core.
License: GPL-3.0 (OwnTV). This patch and the build scripts are distributed under GPL-3.0.

Installable APK is generated by .github/workflows/build-ibo-owntv.yml, standard ARM (arm64-v8a/armeabi-v7a) with applicationId tv.own.iboskyretro. Existing IBO Pro and previous 5.x test players remain untouched.

Features come from the upstream OwnTV codebase: Xtream Codes, M3U and Stalker sources; Live TV, EPG, Movies, Series, search, favourites, recording, multiprofile, and two engines (Media3 1.11.1 and libmpv/FFmpeg). No channels or access credentials are included.

SKY Home: 2 rows x 4 equal rectangular cards; permanently pulsing yellow edges; blue title bars; D-pad focus; routes to OwnTV Live TV, Movies, Series, More/playlist manager, Settings, profile switch, app reload and exit. Other screens retain the functional OwnTV navigation and style.

**Known differences from classic IBO Pro 4.0**: Cinematic poster photo assets are not replicated in this first OwnTV build. Icon art is rendered with vectors. This is an OwnTV full-feature base under a SKY-inspired Home skin; not an exact IBO Pro UX transplant. Media3/mpv startup and Xtream provider operations must be tested on the Sony Bravia.

No IPTV credentials or copyrighted third-party IBO code are included.
