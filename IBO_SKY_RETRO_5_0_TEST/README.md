# IBO SKY RETRO 5.0 test
Clean-room Android TV test APK project, not a patched IBO Pro APK.
Media3 1.11.1, Xtream Codes login, live/movie/series categories and playback, simple 8-tile SKY RETRO layout with blue bars and yellow pulsing borders.
Missing from this test: full 4.0 artwork, EPG, search, favourites, channel preview. Not TV tested.
Do not store IPTV login details in public repositories; the app saves credentials on-device only.
