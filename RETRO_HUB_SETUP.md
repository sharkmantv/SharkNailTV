# Retro console hub
This is an Android external-emulator frontend, not bundled emulation. The existing 12 native arcade games remain. No commercial ROMs, BIOS or emulator binaries are included.
Install RetroArch from https://www.retroarch.com/?page=platforms, open it, grant appropriate shared storage access, and download the core shown in Shark Games > Retro Consoles. Select the installed package, choose a console, enter a title and full shared ROM path, and Add game. The game button requests RetroArch launch using ROM and full LIBRETRO core path. Core paths assume the default private cores folder; custom layouts may require changes. Android storage access, BIOS, core availability and ROM compatibility vary. Arcade collections must match the core's ROM set. For discs use a complete compatible image or cue with all tracks in shared storage. PSP/Dolphin/Moonlight buttons launch their installed apps, not individual games. Moonlight requires a paired host. Commercial titles are examples only. Source-only; no APK or device verification. Reference: https://docs.libretro.com/guides/cli-intro/ .
